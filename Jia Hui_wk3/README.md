# A Whisper in the Fog

A dependency-free first-person mystery game for the browser.

Open `index.html` directly, or serve this directory with any static server:

```sh
python3 -m http.server 8080 --directory mystery-game
```

Then visit `http://localhost:8080`.

Controls: WASD to move, arrow keys to look, E to interact, J for the case journal, and Escape to pause.
