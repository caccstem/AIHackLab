# 🚀 Final Project

## 📋 Overview
Your goal is to build a high-quality, AI-powered application that solves a real-world problem.

| Feature | Requirement |
| :--- | :--- |
| **Team Size** | 2–3 Members |
| **Duration** | Class 9 $\rightarrow$ Class 16 (7 weeks) |
| **Complexity** | Medium to High |

---

## ⚠️ The "Complexity Bar"
Your project must be **functional** and **valuable**. 

> ### 🚫 NOT SUFFICIENT:
> *   **Cloned Repos:** Just changing the CSS/UI colors of a project.
> *   **Tutorial Replicas:** Building exactly what was shown in a tutorial.
> *   **Redundant Tools:** Building something that already exists (e.g., a basic translator or a generic chatbot).

**Your project must solve a problem a human actually has.**

---

## 📅 Project Roadmap

### 📍 Step 1: Requirement Collection
**DUE: End of Class 11**

Before you write a single line of production code, you must complete the discovery phase. You must submit a **1-2 page 
document** including:

#### 1. The "Who" and "Why"
- Identify a specific user persona.
- Describe their problem in **their own words**.

#### 2. The Evidence (Raw Data)
- **Interviews:** Minimum of 3 interviews (15 mins each) with **actual potential users** (not teammates).
- **Surveys:** A Google Form with 10+ responses is highly encouraged.

#### 3. The Scope (Must-have vs. Nice-to-have)
- Clearly define what you **will** build in the remaining 5 classes.
- Clearly list what you are **cutting** to ensure a polished MVP.
