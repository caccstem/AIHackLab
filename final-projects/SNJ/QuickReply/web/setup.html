QUICK SETUP

Bring QuickReply to Gmail

The local server shares your reply library with the Chrome extension. Keep it running while you use Gmail.

1

Start your local server

In Terminal, go to the QuickReply project folder and run python3 server.py. Leave that window open, then open http://127.0.0.1:8766 in Chrome.

2

Load the Chrome extension

Visit chrome://extensions, turn on Developer mode, click Load unpacked, and select the project's extension folder.

3

Create your saved answers

From the reply library, add a common customer question and the response you want to use. Active replies sync to the extension through the running local server.

4

Try draft mode in Gmail

Refresh Gmail and open a message. For a strong question match, QuickReply shows the suggested response. Select Prepare reply, review the draft, and send it yourself.

Auto-send is optional. It is off by default. The extension popup can enable it for strong matches. Keep draft mode on until you have reviewed your replies and matched results. This prototype only supports Gmail in Chrome and stores reply rules on this computer.
