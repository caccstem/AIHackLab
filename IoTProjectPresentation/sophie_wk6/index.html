FROM DEMO TO DEVICE

Connect your ESP32 boards.

Use this page on the same network as your boards. Run python3 server.py and open http://localhost:8000. Addresses are configured in server.py: esp32-1.local, esp32-2.local, and esp32-3.local.

Temperature and humidity are read from /temperature and /humidity. Light buttons request /red_light/on or /red_light/off, with the matching color.

Light indicators show the last successful HTTP command in this page, not measured light status. “Unknown” means no successful command has been recorded, or a request failed. Reloading resets these indicators without changing any lights.

If readings fail, try the temperature URL directly. Use the included server instead of Live Server or opening the HTML file directly. It forwards requests to the boards so they do not need browser CORS support. The error on each card provides more detail.
